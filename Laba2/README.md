# Лабораторная работа №2: Метод k-ближайших соседей и непараметрическая регрессия
## О работе
В этой лабораторной я изучила два непараметрических метода машинного обучения — метод k-ближайших соседей (kNN) и ядерную регрессию Надарая-Ватсона. Главная цель — понять, как разные метрики расстояния и настройки модели влияют на точность прогноза.

## Датасет
Я взяла датасет Used Car Price Prediction с Kaggle. В нём собраны данные о подержанных автомобилях.

Ссылка: https://www.kaggle.com/datasets/ayaz11/used-car-price-prediction/data

## Задача — предсказать цену автомобиля по его характеристикам.

1. Загрузка и разведочный анализ — загрузила данные, почистила их и сгруппировала по категориям, чтобы увидеть закономерности.

2. Подготовка признаков — перевела категориальные признаки в числа, разделила данные на обучающую и тестовую части, отмасштабировала числовые признаки.

3. Поиск лучшего k — перебрала нечётные значения k от 1 до 25 и для каждого посчитала ошибку MAE.

4. Сравнение метрик — обучила две модели kNN: одну с Евклидовым расстоянием, другую с Манхэттенским, и сравнила результаты.

5. Ядерная регрессия — реализовала метод с Гауссовским ядром и подобрала оптимальное значение gamma.

6. Визуализация — построила график «реальные цены против предсказанных» и сделала вывод.

## Бизнес-вывод
Модель хорошо работает для автомобилей массового сегмента — до $40 000. Её можно применять для автоматической оценки машин при трейд-ине, страховании или размещении объявлений. Для дорогих автомобилей модель не подойдёт: она будет занижать их цену.
